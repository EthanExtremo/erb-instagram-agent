# Índice do ERB Instagram Agent

Este repositório usa arquivos na raiz para facilitar o envio pelo aplicativo móvel do GitHub.

- `INSTRUCTIONS.md` — instruções centrais para o GPT.
- `VOICE.md` — voz e identidade editorial.
- `SKILL-ig-reel.md` até `SKILL-ig-audit.md` — 13 módulos.
- `DOCS-CHATGPT-SETUP.md` — configuração do GPT personalizado.
- `DOCS-SAFETY-AND-PLATFORM.md` — segurança e limites.
- `LICENSE` — licença e atribuição.

Os comandos são prompts textuais. O agente não publica nem envia mensagens automaticamente.
