# Configurar no ChatGPT
1. Crie um GPT personalizado chamado **ERB Instagram Agent**.
2. Copie `INSTRUCTIONS.md` para o campo Instruções.
3. Adicione `VOICE.md` e os arquivos `SKILL-*.md` como conhecimento.
4. Habilite pesquisa na web para tendências e regras atuais; análise de dados se for usar planilhas.
5. Teste cada módulo.

Os comandos `/ig-reel`, `/ig-caption` etc. são rótulos de prompt, não comandos nativos. Arquivos Python enviados como conhecimento não são executados automaticamente. Esta versão é um pacote de instruções, não um aplicativo autônomo.
